# 求职通关攻略

> **分工**：本仓库负责从建档、岗位核验到面试/Offer 的求职全流程；ATS 表单操作与人工登录/最终提交交接详见 [campus-apply-copilot](https://github.com/cangyuyi/campus-apply-copilot)。岗位、薪资与政策等时效信息需到原始来源重新核实。

面向中国大陆求职者的 Codex Skill，覆盖个人事实建档、职业定位、公司与岗位搜索、
官方核验、来源快照与变化监控、岗位匹配、一岗一版材料、网申、内推沟通、
笔试面试、Offer 比较、谈薪、签约和求职漏斗复盘。

## 主要能力

- 为任意求职者建立匿名、可核验的个人事实母库
- 覆盖校招、社招、实习、国央企、事业单位、民企和外企在华岗位
- 搜索专精特新、行业龙头、独角兽、创投被投及小而美公司
- 记录搜索进度、保存来源快照、比较岗位变化并生成监控任务
- 根据具体 JD 生成简历、求职信、网申问答和沟通材料
- 准备笔试面试、比较 Offer、统一薪酬口径并生成谈薪方案
- 跟踪投递流程并通过漏斗数据持续复盘

## 安装

将 `china-job-search-playbook` 目录复制到 Codex 的 Skills 目录，或通过支持从
GitHub 安装 Skill 的工具安装本仓库中的同名目录。

安装后的调用示例：

```text
使用 $china-job-search-playbook，根据我的真实情况建立档案，搜索并监控适合的中国大陆岗位。
```

## 隐私

仓库只包含空模板、规则和脚本，不包含任何真实候选人的简历、联系方式或求职台账。
使用时不要把身份证号、银行卡、验证码和完整住址写入工作区。
